## 1. 모델과 기호

전후축 SISO, 라플라스 영역. `analysis/stability_margins.py` 의 `_pieces` 와 같다.

| 기호 | 뜻 | 값 |
|---|---|---|
| P(s) | 명령 → 후미 속도. 평활 1/(τ_s s+1) · 검출·ZOH 지연 e^{−sT_d} · FC 속도루프 1/(τ_fc s+1) | τ_s 0.10, T_d 0.10, τ_fc 0.30(가정) |
| E_p, E_v | IMM-EKF 의 거리 → 거리 추정 / 상대속도 추정 주파수응답 | 실측(28점) |
| A(s) | P+D: (K_p E_p + K_d E_v)/s — 상대 속도를 적분해 거리 오차로 | K_p 0.22, K_d 0.05 |
| B(s) | 피드포워드 KFF/(τ_ff s+1) | KFF 0.8, τ_ff 2.0 |
| C(s) | EKF 상대속도 경로 E_v/s | |
| H_m(s) | 자기 속도 수신 e^{−sT_m}/(τ_m s+1) | T_m 0.10, τ_m 0.30 |
| F(s) | vision 피드포워드 포함 되먹임: A − B(H_m − C) | |
| L(s) | 개루프 P·F (`open_loop`) | GM 14.4 dB, PM 84° |
| T(s) | P·A/(1 + P·A): P+D 만의 보완 감도 | ‖T‖∞ 0.999 |
| B_d(s) | 방송 피드포워드 B·e^{−sT_m} (링크 지연) | |

후미 i 의 속도 v_i, 리더 속도 v_L. 상대 거리 d_i = x_{i−1} − x_i 이고 A 는 (v_{i−1} − v_i) 에 작용한다.

## 2. 정리 1 — 선두 방송 토폴로지의 스트링 안정성

**설정.** 후미 i 는 앞 기체(i−1, i = 1 이면 리더)와의 거리를 카메라로 재고 P+D 를 걸며, 피드포워드는 선두가 방송한
절대 속도 v_L 을 링크 지연 T_m 뒤에 받는다(`formation.py` 의 `ff_source="broadcast"`, `chain_sim(topology="leader_broadcast")`).

    u_i = B_d·v_L + A·(v_{i−1} − v_i),    v_i = P·u_i.

**정리 1.** v_i = T·v_{i−1} + G·v_L, G = P·B_d/(1 + P·A) 이고, 리더→i 단 전달은

    Γ_i(s) := v_i / v_L = P·B_d + Tⁱ·(1 − P·B_d).

따라서 모든 ω 와 i 에 대해 |Γ_i(jω)| ≤ |P·B_d| + |T|ⁱ·|1 − P·B_d| 이다. ‖T‖∞ ≤ 1 이면 (i) 리더→i 단 이득은 i 에 대해 균일 유계
(sup_i ‖Γ_i‖∞ ≤ ‖ |P·B_d| + |1 − P·B_d| ‖∞), (ii) |T(jω)| < 1 인 모든 ω 에서 Γ_i(jω) → P·B_d(jω) (i → ∞), (iii) 인접 단 교란 전달은
i 와 무관하게 T 이므로 체인은 Ploeg 등(2014)의 의미로 L2 스트링 안정하다(‖T‖∞ ≤ 1).

**증명.** v_i(1 + P·A) = P·A·v_{i−1} + P·B_d·v_L 에서 첫 식이 나온다. 귀납으로 Γ_i = Tⁱ + G·(1 + T + … + T^{i−1}) = Tⁱ + G·(1 − Tⁱ)/(1 − T).
1 − T = 1/(1 + P·A) 이고 G = P·B_d/(1 + P·A) 이므로 G/(1 − T) = P·B_d. 삼각부등식으로 상계, |T| < 1 에서 Tⁱ → 0. 교란 v_{i−1} → v_i 의
전달이 T 라는 것은 첫 식에서 v_L = 0 을 두면 된다. ∎

**따름정리.** |P| ≤ 1, |H_ff| ≤ 1 이므로 꼬리 ‖P·B_d‖∞ ≤ KFF. 방송 토폴로지에는 자기 속도 되먹임 경로(H_m − C)가 없으므로 KFF = 1 도
허용된다(단일 후미 정상상태 오차 0, 데드존 몫 0.23 m 제외). 반면 선행기 추종(vision FF)은 Γ_i = Γ_1ⁱ 이고 ‖Γ_1‖∞ = 1.126 > 1 이라
1.126ⁱ 로 발산한다 — Seiler·Pant·Hedrick(2004)이 말한 "상대 정보만으로는 어떤 선형 제어기도 못 피하는" 그 현상이다.

**수치(현재 이득, i = 1..6).**

| 토폴로지 | ‖Γ_1‖∞ | ‖Γ_2‖∞ | ‖Γ_3‖∞ | ‖Γ_4‖∞ | ‖Γ_5‖∞ | ‖Γ_6‖∞ |
|---|---|---|---|---|---|---|
| 선행기 추종 (기존) | 1.126 | 1.269 | 1.429 | 1.610 | 1.813 | 2.042 |
| **선두 방송** | 1.089 | 1.057 | 1.022 | 1.003 | 1.000 | 0.999 |
| 선두 방송, KFF 1.0 | 1.204 | 1.212 | 1.187 | 1.163 | 1.142 | 1.126 |
| 선두 방송, K_p 0.6 | 1.198 | 1.239 | 1.223 | 1.187 | 1.150 | 1.115 |

방송이면 1 단의 피크(피드포워드와 P 응답의 겹침)가 뒤로 누적되지 않고 꼬리로 갈수록 P·B_d 로 내려간다. KFF 1.0 이나 K_p 0.6 은 1 단
피크가 1.2 로 커지지만 여전히 유계이며 단 수와 무관하다.

**주의.** ‖T‖∞ = 0.999 의 피크는 ω → 0 (T(j0) = 1: 모든 후미가 리더와 같은 속도로 감)이다. 정리 1 의 (ii) 는 ω > 0 에서 성립한다.

## 3. 정리 2 — 시간간격 정책 (방송이 없을 때의 자율 대안)

**설정.** 선행기 추종(vision FF)에서 목표 간격을 D = D₀ + h·v_F 로 둔다. 자기 속도 v_F 는 FC 에서 받으므로(H_m) 루프에
−K_p·h·H_m·v_F 가 더해진다.

**정리 2.** Γ_h = P(A + B·C) / (1 + P(F + K_p·h·H_m)). 분자(리더 경로)는 그대로이고 분모만 커지므로 h 가 늘수록 ‖Γ_h‖∞ 는 단조
감소하고, ‖Γ_h‖∞ ≤ 1 인 최소 h 가 존재한다. 비용은 속도에 비례하는 추가 이격 h·v_F 다.

**수치(이분법, 허용오차 1 ms).**

| KFF | h_min | 추가 이격 @0.3 m/s | h_min 에서 PM / GM / Ms |
|---|---|---|---|
| 0.8 (현재) | **1.22 s** | 0.37 m | 99° / 21.5 dB / 1.12 |
| 1.0 | 2.12 s | 0.63 m | 109° / 16.9 dB / 1.19 |

자동차 플래툰의 상수 시간간격 정책(CTH)이 지연 τ 에 대해 h ≳ 2τ 를 요구한다는 결과와 같은 구조다. 이 루프의 등가 지연(플랜트 0.5 s,
EKF 속도 경로 0.7 s)을 생각하면 1.2 s 는 그 범위에 있다. 방송이 있으면 필요 없는 정책이고, 방송이 끊겼을 때(FOLL_TIMEOUT 류)
`formation.enforce_min_distance` 자리에 h·v_F 를 더하는 것으로 구현할 수 있다(코드는 아직 넣지 않았다 — 운용 결정 사항).

## 4. 정리 3 — 포화·이득 전환에 대한 절대안정성 (원판 판별법)

**설정.** 실제 코드에는 선형 모델 밖의 요소가 있다: 명령 포화 `clamp(±MAX_V)`, 불확실성 감속 0.55/0.75/1.0, 추종/정지 전환(정책이
명령을 0 으로), 소프트 데드존 φ(v) = v·max(0, 1 − DB/|v|). 앞의 셋은 모두 **명령 채널에 곱해지는 정적 이득 k(t) ∈ [δ, 1]** 로 쓸 수 있다
(sat(k·u)/u ∈ [0, 1]; 명령 크기가 MAX_V/δ 이하이면 ≥ δ). 소프트 데드존은 φ(v) = v − sat_DB(v) 이고 sat_DB 는 |·| ≤ DB 로 유계라
되먹임 비선형이 아니라 크기 ≤ 0.05 m/s 의 유계 외란이다.

**정리 3 (Khalil, *Nonlinear Systems* 3판 7.1절 원판 판별법).** 명령 채널의 비선형 ψ 가 섹터 [δ, 1] (δ > 0) 에 있고 나이퀴스트 선도
L(jω) 가 실축 위 −1/δ 와 −1 을 지름으로 하는 원판 D(δ,1) 에 들어가지 않으면(그리고 선형 폐루프가 안정하면) 원점은 절대안정하다.
D(δ,1) ⊂ {Re ≤ −1} 이므로 **min_ω Re L(jω) > −1** 이면 모든 δ ∈ (0, 1] 에 대해 한꺼번에 성립한다. 유계 외란(데드존)은 절대안정한
루프의 유한 이득을 통해 유계 오차만 남기며, 정상상태 기여는 KFF·DB/K_p = 0.18 m 다(`test_fixes.py` `FF: 1축 폐루프` 로 이미 확인).

**수치.**

| 설계 | min Re L(jω) | 주파수 | 여유 (1 + min Re L) | 판정 |
|---|---|---|---|---|
| **현재** | −0.237 | 0.99 rad/s | 0.763 | 인증 |
| 수정 전 (2026-09-18 이전) | −0.569 | 1.20 | 0.431 | 인증 |
| K_p 0.4 | −0.352 | 1.16 | 0.648 | 인증 |
| K_p 0.6 | −0.490 | 1.22 | 0.510 | 인증 |
| K_p 0.8 | −0.630 | 1.28 | 0.370 | 인증 |

수정 전 설계도 인증된다는 것은 그때의 스트링 결함(|Γ| 1.8)이 대신호·포화 문제가 아니라 순수 선형(지연 불일치) 문제였음을 말한다.
STABILITY_MARGINS 6절의 "포화가 진동을 깎아 준다" 는 관찰과도 맞다.

**보조(2×2).** 데드존까지 되먹임 섹터 [0,1] 로 두면 Z = I − G 의 에르미트부 최소 고유값 조건이 되는데, 적분기 때문에 ω → 0 에서
감도 S → 0 이라 구조적으로 0 으로 퇴화한다. ω ≥ 0.05 rad/s 에서는 현재 설계 λ_min = 0.076 > 0 이다. 본문 인증서는 SISO 정리 3 이다.

**대신호 확인(실제 코드, `chain_sim`).** 초기 간격 오차 +4 m 계단: 명령이 0.35 m/s 로 20 s 넘게 포화한 채 접근해 최소 간격 3.00 m
(언더슈트 없음), 리더 정지 후 오차 0.00 m. 리더 0.3 ± 0.5 m/s 정현파(명령 포화 상시): 오차 진폭 2.45 → 2.47 m 로 커지지 않는다.
계단에서 25 s 에 오차가 +2.24 m 남는 것은 불안정이 아니라 권한 한계(0.35 − 0.30 = 0.05 m/s 로만 좁혀짐)다.

## 6. 가정과 한계

- SISO 축별. 측면 속도와 기수가 같은 오차를 줄이는 결합, 자세 보상이 축을 섞는 효과는 없다.
- FC 속도루프는 1차 지연 0.3 s 로 가정했다(식별 안 됨). STABILITY_MARGINS 5절의 격자(0.2~1.2 s)가 이 정리들에도 그대로 적용되지만,
  이 문서의 수치는 공칭값이다.
- 수치 인증서다. 정리는 해석적이지만 부등식은 로그 격자 3000점 위에서 평가했다.
- 정리 3 의 섹터는 [δ, 1] 로 δ > 0 이 필요하다. 정지 모드(이득 0)는 적분기 하나 남은 안정(비점근) 모드라, 추종/정지를 오가는 전환은
  dwell-time 또는 공통 Lyapunov 논거가 따로 필요하다(FCR-22 부분).
- 후미 간 충돌 회피, 편대 기하(측면 슬롯)의 비선형 운동학은 다루지 않았다.
- 방송 지연은 상수 T_m = 0.1 s 로 두었다. 패킷 손실·지터는 없다.

## 7. 졸업 논문 관점 — 지금 내용으로 쓸 수 있는가

**학부 졸업논문·캡스톤 결과보고서라면: 충분하고 남는다.** 문제 정의(비전 리더-팔로워), 시스템 구현(인지·추정·미션·제어·MAVLink),
검증 체계(단위 151·폐루프 14·SITL 9·차등 검증), 해석(여유·스트링 안정성·정리 1~3), 확장(편대 토대)까지 한 편의 골격이 이미 있다.
통상의 학부 논문이 요구하는 것보다 해석 장이 두껍다.

**석사 학위논문이라면: 해석 장은 성립하지만 논문 전체로는 아직 아니다.** 심사에서 반드시 나올 질문이 셋 있고, 지금 저장소로는
답할 수 없다.

1. 플랜트 모델은 어디서 왔는가 — τ_fc = 0.3 s 는 가정이다. 정리 1~3 은 공칭 모델 위의 결과이고 격자 강건성으로 버티지만, "식별한
   모델" 이 없으면 설계론의 첫 장이 비어 있다. 실기 로그 한 세트로 채울 수 있다(MULTI_FOLLOWER_FOUNDATION 후속 항목 1).
2. 실험은 어디 있는가 — 실비행 0 회. SITL 은 구현 검증이지 모델 검증이 아니다.
3. 추정기 공분산은 믿을 수 있는가 — NEES/NIS 검사가 없다. 로그의 `gate_d2` 열로 오프라인에서 바로 할 수 있다.
