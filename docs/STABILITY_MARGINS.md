# 바깥 루프 안정성 여유 분석 (2026-09-18, 2026-09-19 갱신)

Jetson 이 만드는 속도 명령 루프(바깥 루프)의 선형 모델을 세워 위상·이득 여유, 감도 피크, 리더→팔로워
속도 전달(스트링 안정성)을 계산하고, 실제 코드(`main.py` 제어 함수 + `imm_ekf.py`)로 돌린 비선형 체인
시뮬레이션과 대조했습니다. **이 분석이 시험 8개가 놓친 결함을 찾았고, 같은 날 코드에 수정을 적용했습니다.**
문서는 수정 전 설계와 현재 설계를 나란히 둡니다. 숫자는 전부 `analysis/stability_margins.py` 가 쓰는
[`stability_margins.json`](stability_margins.json) 에서 왔고, 아래 명령으로 재현됩니다.

```bash
python3 analysis/stability_margins.py --plots      # 표 + docs/images/stability_*.png (약 30초)
python3 analysis/stability_margins.py --identify   # IMM-EKF 주파수응답을 다시 실측 (약 40초)
```

  자기 속도가 피드포워드로 **양성** 되먹임됐습니다. 2026-09-18 에는 저역통과(FF 2.0 s, 정합 0.3 s)로 눌러 14.4 dB / 1.13 을

- **2026-09-19 에 그 경로 자체를 없앴습니다.** IMM-EKF 의 상태 속도를 리더 **절대** 속도로 두고 자기 속도를 예측의 알려진
  입력으로 넣으면(`p' = p + (v − v_ego)·dt`), 리더 속도 추정이 자기 속도에 (수신 지연 0.1 s 만큼 외에는) 반응하지 않습니다.
  자기 위치·속도 되먹임은 지연 없이 들어오고 피드포워드의 자기 경로는 **음성** 되먹임이 됩니다. 이득여유 14.4 → 26.6 dB
  (KV 0 기준). 이 변경의 본래 목적은 IMM 모드 확률(요구도 EST-15)이었고 안정성 개선은 부수 효과입니다.

  정보만 쓰는 등간격 군집은 스트링 안정이 되지 않는다는 고전 결과이고, 해법도 고전적인 **시간간격 정책**입니다: 명령에
  `−KV·v_self` 를 더하면 목표 이격이 `3.0 + (KV/Kp)·v` 로 벌어지고, 이 지연 없는 음성 되먹임이 피크를 누릅니다. KV 0.2 에서
  전후 1.000 / 좌우 1.000 / 상하 0.999 입니다.
- **대가는 정상상태 이격입니다.** (v − KFF·(v−DB) + KV·v)/Kp: Kp 0.22 그대로면 0.3 m/s 에서 0.73 m. 이득여유가 18 dB 남아
  **Kp 0.22 → 0.30** 으로 되사 0.53 m(직전 0.45 m 대비 +0.08 m)입니다. Kp 0.35 부터 피크가 다시 1.02 로 넘습니다(7.2절).
- **실제 코드로 돌린 4단 체인**(6절)이 선형 예측과 6 % 안에서 맞고, 계단 응답의 단별 최소 간격이 3.00 m(수정 전 2.56 m)로

  SITL 재실행은 아직입니다.

## 2. 모델

```
 리더 속도 v_L ─┐
                │  d = x_L − x_F  (상대 거리)              팔로워 자기 속도 v_F ──(FC, 지연 Tm)──┐
                ▼                                                                             │
   ┌─────────── IMM-EKF (실측 FRF) ────────────────────────────────────────────────────────────┤
   │  예측 입력 v_F^m = D_m·v_F,  p' = p + (v̂_L − v_F^m)·dt                                    │
   │  d̂   = E_p·x_L − [E_p(1−D_m) + D_m]·x_F        v̂_L = E_v·[x_L − (1−D_m)·x_F]           │
   │  v̂_rel = v̂_L − v_F^m                                                                     │
   └───────┬──────────────────┬──────────────────────────┬─────────────────────────────────────┘
           │                  │                          │
   Kp·(d̂−D*)          Kd·v̂_rel               KFF·H_ff·v̂_L   (H_ff = 1/(τ_ff s+1))         −KV·v_F^m  (시간간격)
           └──────────────────┴──────────────────────────┴───────────────────────────────────────┘
                    ▼ u
        H_s(s) · e^{−s·Td} · H_fc(s)  ──▶ v_F ──▶ 1/s ──▶ x_F
        평활      검출+ZOH   FC 속도루프
```

전후축 기준이며 좌우·상하는 이득만 다릅니다(`KP_RIGHT/KD_RIGHT`, `KP_UP/KD_UP`). 추정기가 자기 속도를 알려진 입력으로
받으므로 추정 오차는 자기 운동과 무관하고(선형 추정기의 성질), 자기 위치·속도는 수신 지연 `D_m = e^{−s·Tm}` 만 거쳐
되먹임됩니다. `1−D_m` 항은 "FC 가 아직 알려주지 않은 자기 운동" 이 추정기에는 리더 운동으로 보이는 몫입니다.
플랜트 입력 `u` 에서 루프를 끊고 `x_L = 0` 으로 두면

```
L(s) = P(s) · [ Kp·G_p/s + Kd·G_v + KFF·H_ff·G_ff + KV·D_m ],   P = H_s·e^{−s·Td}·H_fc
       G_p = E_p(1−D_m) + D_m,   G_v = E_v(1−D_m)/s + D_m,   G_ff = E_v(1−D_m)/s
```

네 항이 전부 음성 되먹임입니다. 리더 속도에서 팔로워 속도로의 전달은

```
Γ(s) = v_F/v_L = P·(A + B·C) / (1 + L),   A = (Kp·E_p + Kd·E_v)/s,  B = KFF·H_ff,  C = E_v/s
```

이고 n 단 체인 끝의 속도 변동은 `Γⁿ` 입니다. 모든 ω 에서 `|Γ(jω)| ≤ 1` 이면 뒤로 갈수록 진동이 커지지 않습니다
(스트링 안정성). `Γ(0) = 1` 은 구조적입니다 — 피크가 1 을 넘느냐가 문제입니다.

**직전·수정 전 설계(상대속도 추정기)** 에서는 추정기가 `d = x_L − x_F` 만 보고 자기 속도를 몰랐습니다.
`v̂_L = H_m·v_F + E_v·(x_L − x_F)` (H_m = D_m/(τ_m s+1)) 이라 루프에 `−KFF·H_ff·(H_m − E_v/s)` 라는 **양성** 되먹임 항이
남았고, 그 크기가 두 경로의 지연 차이였습니다. 이 문서의 '직전'·'수정 전' 수치는 그 모델과 그 시절 추정기 튜닝
(프레임당 고정 전이행렬, `imm_ekf.LEGACY_TUNING`)으로 계산한 것입니다.

## 3. IMM-EKF 주파수응답 실측

EKF 는 IMM 혼합·적응 R 때문에 선형화 대신 실측했습니다. `imm_ekf.ImmEkf` 에 카메라 전방축으로
`d(t) = 3 + a·sin ωt` (최대 가속 2 m/s² 이하) 를 30 Hz 로 넣고, 정착 후 위치 추정 `d̂` 와 속도 추정 `v̂` 를
최소제곱으로 맞춰 복소 이득을 뽑았습니다(0.03~30 rad/s, 28점).

![EKF FRF](images/stability_ekf_frf.png)

- 속도 추정은 1차 지연에 가깝고, 등속 출발 계단에서 **63 % 도달 0.30 s** 입니다. 예전 `leader_velocity_ff` 주석의
  가정(δ ≈ 1 s)보다 세 배 빨랐고, 그래서 정합 저역통과 τ_m 을 0.3 s 로 잡았습니다.
- 위치 추정은 램프에 정상상태 지연이 없습니다(CV 모델의 2차 추정기 특성. 8 s 후 지연 0.000 m).
- 자기 속도 입력이 0 인 실측이라 이 FRF 는 "리더 운동에 대한 추정기 응답" 입니다. 현재 추정기(체류시간 전이)와 예전
  튜닝(프레임당 전이)을 각각 실측해 JSON 에 `ekf_frf` / `ekf_frf_legacy` 로 둡니다 — 직진 운동에서는 두 응답이 사실상
  같고(63 % 응답 0.30 s 동일), 차이는 선회 판별(EST-15)에서만 납니다.

가정값(τ_fc 0.3 s, Td 0.1 s)에서 1.00 이고 FC 가 느리거나 지연이 길수록 최대 1.19 까지 넘습니다. 시간간격 h = KV/Kp 는 플랜트
지연에 맞춰 잡는 값이라(군집 제어의 h ≥ 2τ 규칙과 같은 성격), FC 속도루프를 SITL 속도 계단으로 식별해 τ_fc 가 0.3 s 보다
크면 KV 를 올려야 합니다. 안정성 결론은 FC 모델 가정에 좌우되지 않고, 스트링 안정 결론은 좌우됩니다.

### 7.5 데드밴드

수정 전: `target = v·clamp((|v|−DB)/DB, 0, 1)`, DB 0.10 → DB < |v| < 2DB 에서 국소 기울기 최대 3.
현재: `target = v·max(0, 1 − DB/|v|)`, DB 0.05 → 기울기 1. 빼는 만큼 정상상태 오차가 `KFF·DB/Kp` 늘어(0.13 m) 폭을 반으로
줄였습니다. 호버 잡음은 τ_ff 가 짧아진 지금은 추정기(E_v)와 명령 평활이 평균내며, 데드존은 바이어스만 막으면 됩니다.

## 8. 한계

- SISO 축별 분석입니다. 좌우 속도와 기수가 함께 `right` 오차를 줄이는 결합, 자세 보상이 축을 섞는 효과는 포함하지
  않았습니다.
- FC 속도루프를 1차 지연으로 놓았습니다. ArduCopter 의 실제 응답(`PSC_VELXY_P`, 가속 제한, 자세 루프)은 SITL 에서
  속도 계단으로 식별해 `τ_fc` 를 확정해야 합니다. 5절 표는 그 전까지의 범위 보증입니다.
- 측정 잡음, 검출 누락, 포화(`MAX_V*`)는 선형 모델에 없습니다. 체인 시뮬레이션에는 포화·데드밴드가 있고 잡음은 없습니다.
- 기수 루프의 EKF 경로는 ego-yaw 보정이 즉시 적용된다고 보고 ATTITUDE 수신 지연 0.1 s 만 넣었습니다.
- 실제 FC 검증은 SITL(`leader_sine`) 까지이고, 그것도 **직전 설계**의 실측입니다. 현재 파라미터(Kp 0.30, KV 0.2, τ_ff 0.1,
  절대속도 추정기)는 아직 SITL 로 재확인하지 않았습니다(예측 0.88). 실기의 FC 속도루프·바람·측정 잡음은 포함되지 않았습니다.
- 시간간격 정책의 스트링 안정은 τ_fc 가정에 민감합니다(5절). FC 속도루프가 0.3 s 보다 느리면 KV 를 올려야 합니다.
